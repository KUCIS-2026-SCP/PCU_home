정보보안학과 소개

미래 디지털 사회를 보호하는 Cyber Security Professional을 양성합니다.

기술에 대한 깊은 이해와 책임감을 바탕으로 디지털 사회의 신뢰를 설계합니다.

정보보안학과는 네트워크, 시스템, 웹, 데이터 등 디지털 환경 전반의 보안 문제를 체계적으로 학습하는 학과입니다.

이론과 실습, 프로젝트를 균형 있게 연결하여 새로운 위협을 분석하고 현장에 적용할 수 있는 실무형 인재를 양성합니다.

EDUCATIONAL GOALS

교육 목표

01

Cyber Security Knowledge

정보보안 핵심 이론과 기술을 학습합니다.

02

Practical Security

실무 중심 보안 교육을 진행합니다.

03

Problem Solving

사이버 위협을 분석하고 문제를 해결하는 능력을 개발합니다.

04

Security Professional

산업 현장에서 요구하는 정보보안 전문가를 양성합니다.

VISION & VALUES

학과의 방향

학과 비전

안전하고 신뢰할 수 있는 디지털 사회를 이끄는 보안 교육의 중심

교육 철학

기초에 충실하고 실전에서 성장하며 윤리적 책임을 실천하는 교육

인재상

전문 지식, 문제 해결력, 협업 능력과 보안 윤리를 갖춘 인재
