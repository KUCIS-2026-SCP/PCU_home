SEC
SECURITY FIELDS

사이버보안 핵심 분야

기초 이론부터 최신 보안 기술까지 폭넓고 깊이 있게 탐구합니다.

Network Security

네트워크 위협 탐지와 안전한 통신 환경을 설계합니다.

System Security

운영체제와 시스템의 취약점을 분석하고 보호합니다.

Web Security

웹 서비스의 취약점을 찾고 안전한 개발을 연구합니다.

Digital Forensics

디지털 증거를 수집·분석하는 과학적 절차를 학습합니다.

Malware Analysis

악성코드의 행위와 구조를 분석해 대응 방법을 찾습니다.

Cloud Security

클라우드 환경의 데이터와 인프라를 안전하게 보호합니다.

AI Security

인공지능의 안전성과 AI 기반 위협 탐지를 연구합니다.

Penetration Testing

공격자의 관점에서 취약점을 검증하고 개선합니다.
