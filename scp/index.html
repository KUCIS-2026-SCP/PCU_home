S.C.P

Security Contents Production

보안을 연구하고, 기술을 공유하며, 함께 성장하는 정보보안 동아리

S.C.P는 사이버보안 기술을 학습하고 다양한 프로젝트와 실습을 통해 실무 역량을 발전시키는 대학 정보보안 동아리입니다.

Research Areas

S.C.P가 학습하고 연구하는 주요 보안 분야입니다.

Penetration Testing

모의침투 및 취약점 분석

실제 공격자의 관점에서 시스템을 점검하고, 발견한 취약점의 원인과 대응 방안을 연구합니다.

관련 프로젝트 →

Digital Forensics

디지털 포렌식 및 침해사고 분석

디스크·메모리·로그 등 디지털 증거를 수집·분석하여 침해사고의 경위를 재구성합니다.

관련 프로젝트 →

Malware Analysis

악성코드 분석 및 대응

정적·동적 분석 기법으로 악성코드의 동작 원리를 파악하고 탐지·대응 방법을 연구합니다.

관련 프로젝트 →

Network Security

네트워크 보안 및 프로토콜 분석

패킷과 프로토콜을 분석하여 네트워크 위협을 이해하고 안전한 네트워크 구성을 연구합니다.

관련 프로젝트 →

Web Security

웹 취약점 분석 및 보안 연구

OWASP Top 10 등 주요 웹 취약점을 실습하고, 안전한 웹 애플리케이션 개발 방법을 공유합니다.

관련 프로젝트 →

Threat Detection

위협 탐지 및 보안 로그 분석

보안 로그와 이벤트를 분석하여 이상 징후를 탐지하고 탐지 룰을 설계합니다.
